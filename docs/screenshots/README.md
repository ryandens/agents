# Reddit tracker screenshots

These screenshots were captured from the worktree's local Next.js development server
using an isolated headless browser and a disposable PostgreSQL database. All account
details, visit titles, URLs and activity counts are synthetic. No production history
or personal browser profile was used. The Next.js development indicator is hidden
only during capture.

- `reddit-overview.png`: estimated page opens and recent reduction trend.
- `reddit-raw-visits.png`: the same date range shown as raw stored visits.
- `reddit-subreddit-drilldown.png`: one subreddit and local day, including raw records.
- `reddit-mobile.png`: the same drill-down at a 390 px viewport; no horizontal overflow.
